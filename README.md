## 🚀 Featured Projects

### 1. Custom ROS 2 Controller for an Omnidirectional Mobile Robot

**C++ · ROS 2 · ros2_control · Gazebo · RViz**

My main robotics project focuses on developing a custom controller for a mobile robot equipped with two steerable OmniDrive modules.

Areas of development include:
- Robot kinematics and steering-angle calculation.
- Wheel velocity and steering-position control.
- Steering alignment before wheel motion.
- Odometry and ROS 2 integration.
- Simulation and controller testing.

🔗 **[View the repository](https://github.com/Thusitha-Madushanaka/ciima_project.git)**

### 2. Configurable Robot Trajectory Planning

**ROS 2 · C++ · JSON · Robot Motion Control**

An extension of my mobile robotics work focused on configuring target poses and executing a sequence of robot movements.

Planned and ongoing development areas include:
- Named destinations and configurable target poses.
- JSON-based trajectory configuration.
- Multi-pose execution and return-to-home behaviour.
- A custom ROS 2 interface for requesting robot movements.

This work is being developed alongside the mobile robot controller. Features will be documented as they are implemented and tested.

### 3. IoT-Based Emergency Vehicle Traffic Management

**C · Arduino · NodeMCU · Firebase · Flutter**

My undergraduate project explored an IoT-based traffic management system designed to prioritize emergency vehicles at traffic intersections.

The system connected a mobile application and Firebase real-time database to a NodeMCU and Arduino-based traffic-light controller.

My contribution focused on the traffic-control firmware and its integration with Firebase.

### 4. Embedded Systems and Digital Design

**Embedded C · Microcontrollers · Digital Logic · FPGA**

A space for selected embedded programming, digital circuit, and FPGA projects as I prepare and document additional work suitable for public release.
